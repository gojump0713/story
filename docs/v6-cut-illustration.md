# v6 — 컷별 DALL·E 삽화 (1컷부터 선택해서 그리기)

## 개요
이모지 자리표시 대신 **실제 DALL·E 그림**으로, 그리고 한꺼번에 자동 생성하는 대신 **뷰어에서 1컷부터 원하는 컷을 골라** 그릴 수 있도록 삽화 흐름을 재설계했다. 자동 동화·내 프롬프트 그림책 **두 모드 공통**으로 동작한다.

## 동작 흐름
1. (상단 바) OpenAI API 키 입력 — 앱(브라우저)에만 저장, 공개 사이트에 내장하지 않음
2. 동화/그림책 생성 → **텍스트·컷 구조만 빠르게** 완성 (각 컷은 이모지 자리표시)
3. 페이지 뷰어에서 컷을 보며 그리기
   - **`🎨 N컷 그리기`** — 지금 보는 컷만 DALL·E로 생성 (이미 있으면 **`🔄 N컷 다시 그리기`**)
   - **`🎨 1컷부터 모두 그리기`** — 1컷부터 순차 생성 (`1/6 …` 진행 표시)
   - 그리는 중: 장면 위 스피너 오버레이 / 페이지 점에 삽화 완료 표시 / `삽화 n/총` 카운트
4. TTS 낭독 · 독후활동 · 책장 저장은 기존대로

## 일관성 유지 (같은 주인공·같은 화풍)
- 책 생성 시 `Story.styleId`(캐릭터 시트 = 시각 ID)를 저장한다.
  - **자동 동화**: 주인공·주제·한국 소재로 구성한 스타일 설명
  - **내 프롬프트 그림책**: 입력 설정에서 추출한 캐릭터 시트(`buildStyleSheet` 결과)
- 어느 컷을 언제 그리든 `cutImagePrompt(styleId, 장면, i, 총컷)`으로 동일 시각 ID를 주입 → 컷이 흩어져 생성돼도 캐릭터·화풍이 유지된다.

## 폴백
- 키 없음: 그리기 버튼을 숨기고 "상단에 키 입력" 안내, 이모지·그라데이션 유지
- 개별 컷 생성 실패: 해당 컷만 이모지 유지(다시 그리기로 재시도 가능)

## 변경 파일
- `src/App.tsx`
  - `Story.styleId` 추가, 생성 지점(자동/폴백/커스텀)에서 styleId 저장
  - `Reader` — 컷별 그리기/다시 그리기, 1컷부터 모두 그리기, 진행 오버레이, 페이지 점 완료표시, 삽화 카운트
  - `Feature` — `drawCut` / `drawAll` / `busyCut` / `drawingAll` 상태
  - `CustomGenerating` — 생성 단계의 이미지 자동 생성 제거(컷 구조만), styleId 저장
  - Meta(기능·사용법) 문구 갱신
- `src/index.css` — `.sb-draw`, `.sb-draw__count`, `.sb-scene__busy`

## 설계 결정
- **키 제공 방식**: 앱에서 사용자 키 입력(보안 권장). 정적 GitHub Pages에 키를 내장하면 JS 번들에서 노출되어 도용·과금 위험이 있어 채택하지 않음.
- **전부 자동 생성 대신 선택 드로잉**: DALL·E 호출 비용·시점을 사용자가 통제. "1컷부터 모두 그리기"로 한 번에 전체 생성도 가능.
