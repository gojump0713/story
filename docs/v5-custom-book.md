# v5 — 내 프롬프트 그림책 (같은 캐릭터·화풍 5~10컷 생성)

## 개요
사용자가 직접 지정한 프롬프트로, **같은 주인공·같은 그림체로 이어지는 5~10컷의 삽화**를 원하는 컷 수만큼 생성해 한 권의 그림책으로 만드는 기능을 추가했다. 기존 "AI 자동 동화"와 나란히 생성 모드 토글로 선택한다.

## 사용 흐름
1. (선택) 상단 바에서 OpenAI API 키 입력 → 실제 GPT 구성 + DALL·E 3 삽화
2. 앱 화면에서 **✍️ 내 프롬프트 그림책** 모드 선택
3. 입력
   - **주인공·그림체 설정(시각 ID)**: 모든 컷에 동일하게 유지될 외형·화풍 (필수)
   - **이야기/장면 프롬프트**: 줄거리 한 단락, 또는 한 줄에 한 컷씩 (비우면 AI가 자동 구성)
   - **컷 수**: 5~10컷 슬라이더
   - **책 제목**: 선택
4. 생성 진행 화면에서 컷별 썸네일이 채워지며 진행률 표시
5. 완성 → 페이지 뷰어 / TTS 낭독 / 독후활동 / 📚 책장 저장 (기존 기능 재사용)

## 일관성(consistency) 유지 방식 — 핵심
DALL·E 3에는 seed/참조 이미지 옵션이 없어 컷마다 그림체·캐릭터가 흔들린다. 이를 다음으로 해결했다.

1. **캐릭터 시트(시각 ID) 1회 생성** — 입력 설정에서 *변하지 않는* 외형·의상·색팔레트·화풍만 영어 한 단락으로 추출 (`buildStyleSheet`). 장면 동작/배경은 제외.
2. **모든 컷 프롬프트에 동일 주입** — 각 컷의 DALL·E 프롬프트 앞단에 캐릭터 시트를 그대로 붙이고 "keep identical across the whole series" 지시를 명시 (`cutImagePrompt`).
3. **컷 분할** — 컨셉/줄거리를 정확히 N개의 컷(한국어 본문 + 영어 장면 묘사)으로 분해 (`planCuts`, json_object). 사용자가 줄바꿈으로 컷을 직접 적으면 그대로 사용.

→ 컷이 바뀌어도 주인공·화풍이 유지된 연속 그림책이 만들어진다.

## 폴백
- 키가 없으면: 캐릭터 시트는 원문 그대로, 컷은 입력 줄(또는 자동 채움) + 이모지 표지로 구성해 오프라인에서도 "책"이 완성된다.
- 개별 컷 이미지 생성이 실패하면 해당 컷만 이모지로 폴백(뷰어에서 그라데이션 배경).
