## 2026-06-05 — v6.2: 이미지 모델 수정 (gpt-image-1 + dall-e-3 폴백)

### 배경 — 실제 5컷 테스트 중 발견
사용자 제공 임시 키로 5컷 그림책 실제 생성 테스트를 돌리던 중 이미지 API 버그 2건 발견:
- `response_format: 'b64_json'` → 400 "Unknown parameter"
- `model: 'dall-e-3'` → 400 "model does not exist" (해당 계정은 dall-e-3 미보유, 현재 모델은 gpt-image-1)
- GPT 동화 생성(캐릭터 시트 + 5컷 분할)은 정상 동작 확인
- (임시 키는 평문 노출 직후 OpenAI 시크릿 스캐닝으로 자동 비활성화되어 이미지 단계 검증은 미완)

### 한 일 (`src/lib/ai.ts`)
- 삽화 모델 기본값을 **gpt-image-1**로, 계정에 없으면 **dall-e-3 자동 폴백**(첫 성공 모델 사용)
- gpt-image-1은 `response_format` 미전송(항상 b64), `quality` 매핑(hd→high, 그 외→medium)
- dall-e-3은 기존대로 `response_format:b64_json`
- 모델별 허용 사이즈 보정(`normalizeSize`), 응답이 b64면 dataURL, url이면 그대로 반환
- 폴백 규칙: 400/403/404(모델 미보유·파라미터 거부)만 다음 모델 시도, 401/429는 즉시 중단
- `VITE_OPENAI_IMAGE_MODEL` 환경변수로 모델 강제 지정 가능(`.env.example` 반영)

### 남은 검증
- 살아있는 키로 라이브에서 실제 삽화 1장 생성 확인 필요(키 노출 금지 — 앱에 직접 입력)

## 2026-06-05 — v6: 컷별 DALL·E 삽화 (1컷부터 선택해서 그리기)

### 목표
이모지 대신 실제 DALL·E 그림으로, **뷰어에서 1컷부터 원하는 컷을 골라** 그릴 수 있게.

### 한 일
- 생성 단계는 텍스트·컷 구조만 빠르게 만들고(이모지 자리표시), **삽화는 뷰어에서 컷 단위로** 생성하도록 통일 (자동/내프롬프트 두 모드 공통)
- 뷰어 컨트롤 추가
  - `🎨 N컷 그리기` / `🔄 N컷 다시 그리기` — 현재 보고 있는 컷만 DALL·E 생성
  - `🎨 1컷부터 모두 그리기` — 1컷부터 순차 생성(진행 표시)
  - 그리는 중 장면 위 스피너 오버레이, 페이지 점에 삽화 완료 표시, `삽화 n/총` 카운트
- 일관성: `Story.styleId`(캐릭터 시트/시각 ID)를 저장해 어느 컷을 그리든 같은 주인공·화풍 유지
  - 자동 모드: 주인공·주제·소재 기반 styleId
  - 내 프롬프트 모드: 생성된 캐릭터 시트를 styleId로 저장
- 키 없으면 그리기 버튼 숨기고 안내(이모지 유지)

### 변경 파일
- `src/App.tsx` — `Story.styleId`, `Reader` 컷별 그리기/오버레이, `Feature` drawCut·drawAll, CustomGenerating 이미지 자동생성 제거(구조만), Meta 문구
- `src/index.css` — `.sb-draw`, `.sb-scene__busy`

### 결정 메모
- 키 제공 방식: **앱에서 사용자 키 입력**(보안 권장) 채택 — 공개 정적 사이트에 키를 내장하지 않음
- 전부 자동으로 그리지 않고 **선택 드로잉**으로 — 비용·통제 모두 사용자 손에

## 2026-06-05 — v5: 내 프롬프트 그림책 (같은 캐릭터·화풍 5~10컷)

### 목표
사용자가 직접 지정한 프롬프트로 **같은 주인공·같은 그림체로 이어지는 5~10컷**의 삽화를 원하는 컷 수만큼 생성해 한 권의 그림책으로 만드는 기능 추가.

### 한 일
- **생성 모드 토글** 신설: `🎲 AI 자동 동화` / `✍️ 내 프롬프트 그림책`
- 내 프롬프트 모드 입력: 주인공·그림체(시각 ID), 이야기/장면 프롬프트, 컷 수(5~10), 책 제목
- **컷 일관성 로직**(`src/lib/custom-book.ts` 신규)
  - `buildStyleSheet()` — 입력 설정에서 변하지 않는 외형·의상·색팔레트·화풍만 추출한 "캐릭터 시트(시각 ID)"를 1회 생성
  - `cutImagePrompt()` — 모든 컷 DALL·E 프롬프트 앞단에 시각 ID를 동일 주입 + "keep identical across the whole series" 명시
  - `planCuts()` — 컨셉/줄거리를 정확히 N컷(한국어 본문 + 영어 장면 묘사)으로 분할(json_object)
  - `renderCut()` / `clampCuts()` — 컷 단위 생성·범위 보정
- `CustomGenerating` 컴포넌트: 컷별 썸네일 그리드 + 진행률 바 실시간 표시
- 책장 표지에 첫 삽화 노출, 기존 뷰어/TTS/독후활동/책장 그대로 재사용
- 폴백: 키 없으면 이모지 컷으로 오프라인에서도 책 완성, 개별 컷 실패 시 해당 컷만 이모지

### 일관성 설계 메모
DALL·E 3에는 seed/참조 이미지가 없어 컷마다 그림체가 흔들린다. → 시각 ID를 한 번 만들어 전 컷에 동일 주입하는 방식으로 캐릭터·화풍 연속성을 확보.

### 변경 파일
- `src/lib/custom-book.ts` (신규)
- `src/App.tsx` — 모드 토글·커스텀 폼·`CustomGenerating`·책장 표지·Meta 정보
- `src/index.css` — `.sb-mode`, `.callout-soft`, `.cg-bar`, `.cg-grid` 등
- `docs/v5-custom-book.md` (상세 설계 문서)
